Aprenda a conectar seus projetos ao mundo em apenas 4 passos usando o codingcms.vercel.app

01

Acesso ao Hub

O primeiro passo é acessar o nosso portal em codingcms.vercel.app.

Lá você deve inserir suas credenciais do **CodingCourse**. O sistema é blindado: apenas alunos ativos podem criar servidores.

  • Use seu Usuário da plataforma
  • Insira seu Código de Acesso único

02

Criando o Servidor

No seu painel, você verá a opção de criar um novo servidor. Ao clicar no **ícone de Plus (+)**, o Hub gera um código único de 6 dígitos.

Aguarde o status: SINCRONIZADO

Este código é o que faremos nosso jogo "ouvir" para saber quais são as coordenadas dos jogadores, vida, e itens.

03

O Script de Conexão

Agora a mágica acontece. Use o código abaixo para que seu jogo se conecte ao servidor que você acabou de criar. Substitua o `CODIGO_AQUI` pelo seu código gerado.

async function conectarAoMundo() {
  // Buscando dados do servidor no CodingCMS
  const res = await fetch('https://codingcms.vercel.app/api/lobby/join/CODIGO_AQUI');
  const dados = await res.json();

  console.log("Variáveis do Professor:", dados.variables);
  // Agora use esses dados para posicionar seus players!
}
04

Gerenciando as Variáveis

No Dashboard, você pode adicionar variáveis como `dificuldade`, `gravidade` ou `tempo`.

Toda vez que você altera um valor no painel, o sistema **Redis** atualiza o valor global instantaneamente. O seu jogo, através do script do Passo 3, receberá esses novos valores automaticamente.
