Aprender a Programar Manual para IAs

1. Login e Criação

API de Integração

Use os endpoints REST para controlar o fluxo do seu jogo de qualquer plataforma.

GET /api/lobby/join/{CODIGO}

Retorna os dados do servidor e todas as variáveis atuais.

// Resposta de Sucesso: { "code": "X7K2B9", "channel": "uuid-canal-secreto", "variables": { "status": "aguardando", "players": "2/4" }, "owner": "fardinando" }
POST /api/lobby/update

Atualiza ou cria novas variáveis para o servidor.

// Enviar JSON: { "code": "X7K2B9", "variables": { "pos_x": "150", "hp": "90" } }

Scripts de Implementação

Exemplos universais para você usar no seu motor de jogo.

Javascript / Fetch

async function conectarMultiplayer(codigo) {
    const res = await fetch(`https://SEU-HUB.vercel.app/api/lobby/join/${codigo}`);
    const data = await res.json();
    
    if (data.error) {
        console.error("Lobby não encontrado!");
        return;
    }

    console.log("Conectado ao canal:", data.channel);
    console.log("Variáveis iniciais:", data.variables);
    
    // Iniciar loop de sincronia...
    setInterval(async () => {
        const sync = await fetch(`https://SEU-HUB.vercel.app/api/lobby/join/${codigo}`);
        const freshData = await sync.json();
        processarVariaveis(freshData.variables);
    }, 2000);
}

"Crie um script em JavaScript que conecte meu jogo a um sistema de multiplayer via API REST. A URL base é [SUA-URL], eu uso um código de sala de 6 dígitos para buscar as variáveis 'pos_x', 'pos_y' e 'hp' de um Redis. Implemente uma função de 'update' que envia minha posição a cada 100ms."
